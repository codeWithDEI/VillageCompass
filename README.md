# VillageCompass

Was bewegt Rötgesbüttel? VillageCompass soll Menschen im Ort ermöglichen, Ideen einzubringen und bis zu fünf Themen als besonders wichtig auszuwählen. Themenwolke und Rangliste machen die Prioritäten sichtbar – insgesamt und nach Altersgruppen.

## Einfach beteiligen

Es gibt eine gemeinsame offene Beteiligungsphase: Ideen einreichen und freigegebene Themen priorisieren ist gleichzeitig möglich. Die eigene Auswahl bleibt bis zum Ende änderbar.

Kinder und Jugendliche erhalten eine eigene, gleichwertige Stimme. Wer kein Smartphone oder keine digitalen Vorkenntnisse hat, kann dieselbe Anwendung mit neutraler Unterstützung vor Ort nutzen. Helfende erklären und bedienen bei Bedarf; die teilnehmende Person entscheidet selbst und nutzt ihren eigenen Code.

Ein persönlicher Code je Person verbindet selbstständige und betreute Teilnahme. Ein eigener Papier-Abstimmungsprozess ist nicht vorgesehen.

## Klare Aufgabe und klares Ende

Das Tool sammelt und priorisiert Themen, auch als Grundlage für den Zehnjahresplan. Anschließend wird einer dieser Abschlüsse dokumentiert:

- An einen Ausschuss übergeben
- Kleinigkeit direkt erledigt
- An einen Verein oder eine Personengruppe übergeben

Eine Übergabe bedeutet noch keine Umsetzung. Die weitere Projekt-, Budget- und Aufgabenverwaltung liegt außerhalb von VillageCompass.

## Projektstand und Mitarbeit

**Konzeptphase:** Der [Anforderungskatalog Version 0.4](docs/requirements.md) beschreibt zwölf Kernanforderungen und die noch offenen Entscheidungen. Das Repository enthält bislang Dokumentation, keine ausführbare Anwendung.

Der separate private Prototyp dient als Gesprächsgrundlage und nutzt Beispieldaten. Die Ergebnisse einer späteren Beteiligung sollen ein Stimmungsbild liefern, keine automatisch repräsentative Umfrage.

Die Anforderungen werden mit einer kleineren Arbeitsgruppe weiter ausgearbeitet. Rückmeldungen und Änderungsvorschläge können über Issues und Pull Requests eingebracht werden.
